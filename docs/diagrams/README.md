# 图表资产说明

本目录存放《APS林德叉车生产落地开发方案》使用的图表。

## assembly-sop-gantt

- `assembly-sop-gantt.svg`：矢量源文件，可直接在浏览器打开，或嵌入 Markdown。
- `assembly-sop-gantt.png`（可选）：2× 位图，可由浏览器打开 SVG 后导出，用于汇报与打印。

图中内容为叉车整机机械装配（总装）的 SOP 联动视图：

- 上半部分：资源甘特图（总装 A 线各工位、测试台架 T1/T2、线边齐套），红色折线表示工序前后置关系。
- 下半部分：订单甘特图（每张订单从齐套到测试放行的生命周期）。
- 绿色菱形表示齐套放行；红色虚线框表示齐套未达标、不得上线的占位。

图中的节拍、换型与齐套数据均为示意值，生产使用前须按本厂 3–12 个月数据标定。

## assembly-multi-stage-sop

- `assembly-multi-stage-sop.svg`：矢量源文件，可直接在浏览器打开，或嵌入 Markdown。
- `assembly-multi-stage-sop.png`（可选）：2× 位图，可由浏览器打开 SVG 后导出。

图中内容为机械装配行业的三段协同 SOP（SOP-APS-02）：

- 资源链路：激光下料 → 数控折弯 → 车架/门架焊接 → 面漆线 → 烘干炉 → 总装 A 线 → 测试台架。
- 彩色条按订单区分；斜纹块表示换色（30 min）与换型（15/10 min）。
- 红色折线表示工序前后置；虚线框表示待齐套、不得上线的订单。
- 下半部分为段间 WIP 水位与周目标（换色次数、烘炉 OEE、缺件停线）。

图中的节拍、换色、换型与 WIP 数据均为示意值，生产使用前须按本厂 3–12 个月数据标定。

## assembly-practice-sop

- `assembly-practice-sop.svg`：机械装配行业实践 SOP，左侧六步作业流，右侧资源甘特执行底图、五条铁律、L1–L3 升级与验收 KPI。
- `assembly-practice-sop.png`（可选）：2× 位图，可由浏览器打开 SVG 后导出。

图中内容对应每日 06:30–08:00 的排产作业与班中执行：

- 六步：订单与配置 → 齐套与 CTP → 有限能力求解 → 人工干预与主管确认 → 冻结发布与配送 → 执行报工与异常。
- 右侧甘特对应 README 两张截图的资源泳道、任务条、前后置箭头与任务详情。
- 铁律、升级时限与 KPI 为实践口径，需按本厂组织与数据标定。

## timefold-llm-presolve-flow

- `timefold-llm-presolve-flow.gif`：README 首页用示意动图（约 10 秒循环），演示 Timefold + 小模型前置求解处理急单插入的全过程。
- `gen_timefold_presolve_gif.py`：动图生成脚本（依赖 Pillow），修改脚本后重新运行即可再生成。

动画内容为叉车整机装配场景的动态重排：

- 流程：动态事件（急单 E7 落入）→ 小模型前置求解（事件结构化、约束增量、初始解种子沿传送带流向求解器）→ Timefold 组合优化（锁图标标记在制任务、被牵连的 4 根条过冲回落式搜索、硬约束违背 12→0）→ 解释归因与冻结发布。
- 甘特为六工位执行底图（底盘、门架、液压、电气、属具、测试台架），彩色条按订单区分，红条为新增急单。
- 节拍、时长与"0.3s/8min"耗时均为示意值，生产使用前须按本厂数据标定。
